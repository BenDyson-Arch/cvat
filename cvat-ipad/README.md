# CVAT Local for iPad

This is an iPad-only Capacitor shell for the local annotation workspace. The
interface is bundled into the app; it does not require Docker or a running CVAT
server. The annotation workspace imports the existing `cvat-ui` annotation page,
touch header, tool dock, brush tools, object drawer and settings directly. Local
data is supplied by a `Job` adapter using CVAT's annotation collection and history.

The first prototype supports importing an aligned stack of same-sized images,
shared annotation coordinates across its views, and masks, points, rectangles,
and polygons. Projects save on the device. Export produces a JSON annotation
file through the iPad share sheet.

Upload, user accounts, CVAT task synchronisation, video, and a two-way server
sync are intentionally not included yet.

## Prerequisites

Build and install the iPad app on a Mac with Xcode 26 or newer. Use Node 22 or
newer. Copy or check out this whole repository including the iPad changes; the
app reuses the sibling CVAT packages. First install the repository dependencies
from its root (Corepack/Yarn must be available):

```sh
corepack yarn install --immutable
```

Then install the iPad package's dependencies:

```sh
cd cvat-ipad
npm ci
```

## Install on an iPad

Connect the iPad to the Mac, unlock it, and trust the Mac if prompted. From the
same directory run:

```sh
npm run ios:sync
npm run ios:open
```

In Xcode, choose the `App` target, select the connected iPad as the run
destination, then set your Apple development team under **Signing &
Capabilities**. Press Run.

The generated target is iPad-only and requires iPadOS 16.0 or newer. Its bundle
identifier is `org.cvat.local`; change it in Xcode if it conflicts with another
app under your Apple development team.

Repeat `npm run ios:sync` after changing the web editor, then run again from
Xcode. `npm run ios:open` only opens the project; it does not rebuild the web
editor.

## Local data and exports

Images and project metadata remain in the app's private on-device storage.
Use **Menu → Export annotations** to send the annotation JSON to Files, AirDrop, or
another installed share target. Removing the app removes its private project
storage, so export important work before uninstalling.

The JSON is a local prototype export format (`cvat-local-aligned-stack`), not
yet a full CVAT task backup or an upload payload.

Import supports PNG, JPEG and WebP. Views must already be registered and have
identical pixel dimensions; this app does not align them automatically. All
views share one annotation layer, rather than separate masks per depth slice.

Use the existing **Next annotation** control to commit a mask, and **Done** for
points or polygons. Completed objects and edits save automatically. Unfinished
drawing can be lost if the app is force-quit. Undo is session-local and bounded
to limit memory use; it does not survive
closing a project. Full-resolution images and active masks still consume memory,
so large stacks need testing on the target iPad.

## Development and checks

From `cvat-ipad`, `npm start` serves the editor at `http://127.0.0.1:3001` without
a backend. Browser previews store projects in IndexedDB; the installed iPad app
uses native files. The preview and installed app do not share storage.

```sh
npm run type-check
npm test
npx playwright install chromium
npm run test:e2e
```

Browser tests exercise import, mask/shape drawing, aligned view switching,
undo/redo, local reopen and annotation export. These do not replace testing
Pencil gestures, native saving and the share sheet on a physical iPad.

## Native project notes

`ios/` was generated by Capacitor. Its privacy manifest declares the file
timestamp access used by the filesystem plugin. The app uses Capacitor's
filesystem and share plugins; it does not request Photo Library or Camera
permission because images are selected through the Files picker.

Project metadata is saved through a small bundled iOS plugin using Foundation's
atomic file replacement. It accepts only UUID project identifiers and always
writes `projects/<project-id>/project.json` in the same Documents location used
by Capacitor's `Directory.Data` on iOS.
